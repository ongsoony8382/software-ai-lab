# 컴퓨터 개요

## 1. 컴퓨터의 구성
컴퓨터 = **하드웨어 + 소프트웨어**  

컴퓨터는 크게 **CPU, 메모리(휘발성), 보조기억장치(비휘발성)**로 구성됨.  
- **메모리**: 현재 실행되는 프로그램의 명령어와 데이터를 저장하는 부품 

---

## 2. 소프트웨어의 종류
- **시스템 소프트웨어**: 운영체제, 컴파일러 등
- **응용 소프트웨어**: 워드프로세서, 스프레드시트, 프레젠테이션 등

---

## 3. 프로그래밍 언어의 종류
- **기계어**
- **어셈블리어**
- **고급언어**  
  > 고급언어는 반드시 기계어로 번역하여 실행  
  - **컴파일러 언어**
  - **인터프리터 언어**

---

## 4. 변수
- **변수**: 프로그램에서 값이나 연산의 결과 등을 저장하는 곳
- **변수 이름 규칙**
  1. 첫 번째 문자는 **영문자** 또는 **밑줄(_)**
  2. **대소문자 구분** (예: `age`, `AGE`, `Age`는 모두 다른 변수)
  3. **예약어는 변수 이름으로 사용 불가**

## 1. 알고리즘이란?
문제 해결을 위해 특정한 일을 수행하는 명령어들의 집합

### 알고리즘이 만족해야할 조건
- **입력**: 0혹은 그 이상의 입력이 존재
- **출력**: 적어도 하나 이상의 결과물이 출력
- **명확성**: 알고리즘을 구성하는 명령어들의 의미는 명확해야 하며, 애매모호해서는 안 됨.
- **유한성**: 알고리즘은 한정된 수의 명령어들을 실행한 후 종료하여야 함.
- **유효성/실행가능성**: 모든 명령어들은 실행 가능해야 함.

---

## 2. 명령어들의 세 가지 구성 방법
- **순차구조**: 하나의 명령을 처리한 후, 다음 명령을 차례대로 하나씩 실행하는 구조
- **조건구조**: 여러 개의 명령어 중에서 조건에 따라 하나를 선택하여 실행하는 구조
- **반복구조**: 특정 명령(들)을 여러 번 실행하는 구조
